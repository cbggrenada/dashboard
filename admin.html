Uploads and changes are saved straight to GitHub, which stays the master copy. You need a GitHub access token for the dashboard repository (see below).

The token is stored on this device only, locked with your passcode. Next time you only need the passcode.

How do I get an access token?
  1. Sign in to GitHub with the account that owns the dashboard, then open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it Dashboard admin and choose an expiry (for example 90 days).
  3. Under Resource owner choose the account that owns the repository (cbggrenada).
  4. Under Repository access pick Only select repositories and choose the dashboard repository.
  5. Under Permissions → Repository permissions set Contents: Read and write and Actions: Read and write.
  6. Click Generate token, copy it and paste it above.
